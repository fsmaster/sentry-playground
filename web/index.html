Sentry Playground

Every button sends a real event to Sentry from a small sample app. Each click gets new run id, so you always get new event, not a duplicate. Source for everything is on GitHub.

Saved in this browser only. All events from this page and from the server samples go to that one project, any platform is ok. Not included: CI samples (they run in our GitHub Actions), and our source maps / debug symbols are uploaded to our org, so minified JS and native crashes will show addresses in yours. Careful with alert rules on that project: "new issue every click" means a new issue every click. Only sentry.io DSNs, no self-hosted.

1. What Sentry can show

Browser app (this page) + Node backend + a C program for crashes.

2. One sample per SDK

Error-only samples. Each repo has its own guide you can follow with copy-paste.

Links to Sentry open the fsmaster org, you need access to see them.
